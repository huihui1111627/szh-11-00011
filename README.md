# 火星基地生命保障推演系统（MLSS）

零依赖、可离线运行的单页应用：统一协调 **氧气 / 水循环 / 舱压 / 电力 / 乘员活动**，
支持调度操作的**延迟连锁计算、因果链追溯、事务式回滚、多套救援策略并行对照**，
并自动存档——关闭页面后重新进入可继续未完成的生存推演。

## 运行

直接双击 `index.html`，或启动任意静态服务器：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 测试

```bash
node test/smoke.js        # 37 项引擎规则测试（Node，无依赖）
node test/browser.mjs     # 真实 Chromium 端到端冒烟（需全局 playwright）
```

## 功能与需求对照

| 需求 | 实现 |
| --- | --- |
| 主界面持续展示舱室资源流向与剩余保障时间 | `index.html` 拓扑图（空气/电力流向动画、节点实时分压）+ 顶部六项保障时间（`js/ui/metrics.js`，引擎 `js/engine/forecast.js`） |
| 关闭泄漏舱段 | 点击舱室 →「封闭舱段」：所有相邻舱口立即从气体网络断开（`seal` 命令）；低压时开舱有**压差锁**禁止误操作 |
| 调整氧气分配 | 舱室面板「氧气分配阀」滑块：改权重，电解 O₂ 按权重经管道**延迟 1 分钟**送达（`valve` + `inflowDelayTicks`） |
| 改变设备优先级 | 每台设备 P+/P− 调整卸载优先级；电力不足时按优先级自动卸载并产生因果告警（`stepPower`） |
| 安排乘员转移 | 转移对话框：BFS 校验连通路径、目标容量，按舱段距离计算 ETA；到达时目标封闭则滞留舱外消耗舱外服 O₂ |
| 连续计算操作对其他舱室的延迟影响 | 每分钟一个 tick：舱口双舱交换混合（质量守恒、无条件稳定）、O₂/CO₂/压差跨舱逐步传播；「延迟影响预测」页对**任意操作先试演 120 分钟**再决定是否提交 |
| 资源争用 / 压力失衡 / 备用设备无法同时启动 → 因果链与可恢复节点 | 电力缺口级联卸载；冷备设备**启动窗口互锁（1 台/次）+ 浪涌功率裕量校验**；每条严重/失败事件带分步因果链，链上挂「封闭/增配 O₂/启动备用/回滚」等恢复动作 |
| 多套救援策略同步推进与对照 | 底部策略栏：克隆当前方案分叉、同步时钟推进；「方案对照」表对综合保障、乘员、水、电、最低舱压、泄漏数等指标标绿/标红 |
| 失败操作不覆盖上一稳定状态 | 所有命令走**克隆体试算 → 成功才提交**（`js/engine/manager.js` `command()`）；每次成功操作前自动留「操作前」快照 |
| 重新进入继续推演 | `localStorage` 防抖自动存档 + 刷新/关闭前强制落盘（`js/engine/persist.js`）；重入自动恢复全部方案，另有 JSON 导出/导入 |

## 推演模型（玩法标定，非真实工程参数）

- 每 tick = 1 模拟分钟；9 个舱室、12 条舱口构成环形-辐条气体网络。
- 气体以「分压 × 容积」记账：O₂ 呼吸消耗、CO₂ 呼出/洗涤、高压安全泄放、
  三档泄漏（轻微/严重/灾难）、开启舱口的对流与组分扩散。
- 电力：反应堆 + 备用燃料电池（冷态启动需预热、产生浪涌）、电池充放；
  容量不足按设备优先级卸载。
- 水：饮用水/废水双储箱，乘员用水 + 水回收净化器循环。
- 乘员：缺氧/高 CO₂/低压累计危险暴露 30 分钟减员；转移中依赖舱外服 O₂。

## 代码结构

```
js/engine/   纯逻辑、无 DOM（可在 Node 直接测试）
  config.js    舱室/管线/设备/物理常数
  state.js     初始状态与事件结构
  sim.js       tick 仿真：调度、转移、电力、气体、水、危险暴露、告警
  forecast.js  只读前向推演与剩余保障时间
  commands.js  事务式命令（校验 + 失败因果链/恢复建议）
  manager.js   多策略、自动/手动快照、回滚、对照
  persist.js   localStorage / 导入导出
js/ui/       渲染与交互（拓扑、调度面板、预测、事件、快照、指标、策略栏）
js/main.js   时钟循环与命令分发
test/        Node 规则测试 + Chromium 端到端
```
