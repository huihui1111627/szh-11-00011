# 阿瑞斯基地 · 火星生命保障生存推演系统

零依赖纯前端模拟：统一协调 **氧气 / 水循环 / 舱压 / 电力 / 乘员活动**，在微陨石击穿实验舱、
尘暴削弱太阳能的事故场景下，指挥多套救援策略并对照推演，撑到 8 小时后救援穿梭机抵达。

## 运行

无需构建、无需安装依赖，任选其一：

```bash
# 方式一：直接双击 index.html（file:// 即可，localStorage 可用）
open index.html

# 方式二：本地静态服务器
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

> 快捷键：空格 暂停/继续 · 1/2/3/4 切换 1×/30×/100×/300× · C 打开策略对照 · Esc 关闭

## 想定

- **T+0**：微陨石击穿实验舱（LAB）外壳，舱体持续失压，舱内 2 名乘员（含 1 名伤员）受威胁
- 尘暴抵达，太阳能出力降至 25%（6 小时后恢复），电池仅能支撑约 5 小时
- **T+8:00:00**：救援穿梭机抵达，目标是让尽可能多的乘员存活

不作为 → 约 48 分钟全员牺牲；规范处置（转移 → 隔离 → 修补 + 电力管理）→ 全员生还。

## 你可以做的操作

| 操作 | 入口 | 系统的连锁校验 |
| --- | --- | --- |
| 封闭泄漏舱段 | 点击气闸/水管 → 封闭 | 有人舱室会变孤岛时**拒绝执行**，给出因果链 |
| 调整氧气分配 | 舱室详情 O₂ 配额滑杆 | 制氧机按「配额 × 在册人数」分配，路径封闭会形成局部富氧/火险 |
| 设备优先级 P1–P4 | 设备卡片 | 电力不足时数字越大越先被自动切除，并记录因果事件 |
| 启停备用设备 | 设备卡片 / 基地总览 | 备用制氧机与燃料电池共用**启动母线，不能同时冷启动**；启动峰值电力不足会被拒 |
| 乘员转移 | 舱室详情选择目的地 | 气路可达性校验，每道气闸 45 秒延迟；途中气闸被封会滞留 |
| 乘员活动强度 | 休息/正常/作业 | 影响 O₂ 消耗（−25% / 基准 / +25%） |
| 修补破洞 | 泄漏舱段 | 必须先清空乘员并封闭全部相邻气闸，修补 10 分钟 |

## 核心机制

- **连续物理推演（1 秒/步）**：O₂/N₂/CO₂ 分压、水/废水液位、管道延迟队列（气 12–18s、水 20–30s）。
  气体流动采用「同一时刻压力快照 → 两遍统一扣气」，保证质量守恒；资源经管道到达其他舱室有真实延迟。
- **剩余保障时间**：对每个有人舱室实时推算 O₂、CO₂、失压、饮水四项临界时间，取全基地最短板
  （含电池可支撑时间）显示在舱室卡片、策略标签与底部状态栏。
- **因果链**：每个事件记录其直接诱因（如「尘暴 → 电池耗尽 → 分级断电 → 净化装置切除 → CO₂ 超标」），
  事件面板逐级回溯；告警与被拒操作都附带「可恢复节点」建议。
- **稳定点保护**：每次成功操作写入稳定点快照；**任何失败/异常操作都先克隆再回滚，绝不污染当前状态**。
  事件列表中的「稳定点」标签可点击回退，也可用底部按钮一键恢复。
- **多策略同步推进 + 对照**：可从当前态势「分叉」出独立救援路线，所有策略以相同时钟并行推演；
  ⚖ 对照面板给出指标表（生还/保障余量/电池/最低 O₂/最高 CO₂/舱压/水量）与火花线趋势。
- **持久化**：每次变更与推进自动存入 `localStorage`（保留最近 5 个稳定点快照），关闭重开后
  从断点继续；支持 JSON 导出/导入与一键重置。

## 代码结构

```
index.html            主界面（态势图 + 检查器 + 事件链 + 策略对照）
styles.css            暗色测控台主题
js/sim/
  utils.js            单位换算、物理常数、阈值
  config.js           舱室布局/管道/设备目录/乘员/想定参数
  engine.js           物理与电力推演、设备状态机、操作动作层（校验/因果失败返回）
  scenario.js         事故初始状态与初始事件链
  persistence.js      localStorage + JSON 导入导出
  store.js            多策略、稳定点快照、失败动作隔离、自动存档
js/ui/
  schematic.js        SVG 舱室流向图（流动动画、泄漏、选中态、迷你余量条）
  inspector.js        舱室/管道/基地详情与全部操作控件
  events.js           事件链渲染、因果回溯、失败 toast
  compare.js          多策略对照表 + 火花线
  app.js              主循环（真实帧 × 倍率，所有策略同步推进）与全局绑定
```

## 设计取舍

- 为保证零依赖与可中断/可恢复，所有状态都是可 JSON 序列化的普通对象；管道延迟用资源包队列建模。
- 电力母线按全局统一调度（电力线仅作态势展示），负载按 P1 生保关键 → P4 可牺牲分级自动切除，
  并在电池低水位时提前卸载，避免无意义的抖动。
- 火星表面为 0.6 kPa 真空节点；泄漏舱向表面排气，隔离时在途气体包会退回来源舱而非继续泄入。
